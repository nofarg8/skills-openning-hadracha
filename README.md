# סקיל: פתיחת שיעור מסקרנת

נופר גרגרוד | פיתוח חשיבה | https://nofarg8.github.io/Link-in-bio-Nofar/

סקיל שבונה לך פתיחת שיעור של 5 עד 7 דקות, לכל תחום דעת, לכיתות א'-י"ב, כולל התאמות לחינוך המיוחד.

סקיל הוא "מתכון" שכותבים פעם אחת, וכלי ה-AI מפעיל אותו לבד בכל פעם שמבקשים. במקום להסביר מחדש בכל שיחה מה זו פתיחה טובה, הכלי כבר יודע.

## מה מקבלים

1. הסקיל שואל כמה שאלות קצרות. אפשר גם לצרף מצגת, מערך או סיכום של השיעור.
2. הוא מציע 3 פתיחות קצרות, מ-3 סוגים שונים.
3. את בוחרת אחת, והוא מרחיב אותה: מה את אומרת מילה במילה, מה התלמידים עושים, שאלות מנחות, תשובות צפויות ותפיסות שגויות, הגשר לשיעור, זמן וחומרים, והתאמות אם צריך.
4. בסוף הוא מציע שינויים: קצר יותר, עם יותר תנועה, בלי חומרים ועוד.

הסקיל נשען על חקר מקדים של מה שמעורר סקרנות בכיתה. העיקרון המרכזי: פתיחה טובה פותחת שאלה שהשיעור עצמו עונה עליה.

שני דברים שהסקיל מקפיד עליהם:

- **רעיונות שלא חשבת עליהם.** הוא לא מסתפק ברעיון הראשון והמוכר, ומחפש זווית חדשה לנושא.
- **לקויות בכיתה לא מכבות את הפתיחה.** גם בכיתה עם כמה צרכים יחד, הוא בונה קודם פתיחה מסקרנת ורק אחר כך מתאים את אופן ההעברה, בלי להוריד את רמת החשיבה.

## התקנה

1. להוריד את הקובץ: [lesson-opener-by-nofar.zip](https://github.com/nofarg8/lesson-opener-skill/raw/main/lesson-opener-by-nofar.zip)
2. בכלי ה-AI שלך, לפתוח את אזור הסקילים ולבחור בהעלאת סקיל.
3. להעלות את קובץ ה-zip כמו שהוא, בלי לחלץ אותו.

את ההעלאה כדאי לעשות מהמחשב, בדפדפן. אחרי שהסקיל הועלה אפשר להשתמש בו גם מהנייד.
